## 1. Aprovechar las herramientas — caso "olor del estiércol"

Sebas pidió un mapa AMPLIO de soluciones mundiales al olor del estiércol (no embudo). Se hizo con
fuentes reales (Consensus/PubMed/web, ~26 papers). **Hallazgo de método:** ningún agente actual sirve
para "mapear el espacio de soluciones de un problema" — el convergente es embudo N→1, el divergente
genera demanda, el científico es proteínas. Lo hizo el asistente a mano, NO el sistema → el sistema
**carece de un agente de "investigación amplia"**, y las fuentes/herramientas sí dan para trabajo sólido.

## 2. Rethink — convergencias CERRADAS esta sesión

- **Entregable = "expediente de decisión", NO "el sistema decide/elige el producto".** El humano elige;
  el sistema le arma la decisión. (Pedirle que elija = la trampa del "GO" hueco de ayer.)
- **Múltiples puertas de entrada**, no pipeline lineal demand-first: sector / dolor conocido / tecnología
  de un científico / planta o recurso / necesidad de un empresario. Demand-pull Y supply-push convergen
  al MISMO artefacto.
- **"Blue ocean" definido concreto** = cruce de 4: (1) demanda real no resuelta, (2) capacidad/tecnología
  que la resuelve, (3) competencia débil/ausente, (4) viable en contexto.
- **Esqueleto del expediente (cerrado; el DETALLE de campos queda para después):**
  1. Tesis + puerta de entrada
  2. Los 4 cruces del blue ocean (cada uno: verificado / asumido / a-confirmar)
  3. Mapa de confianza (qué está verificado con fuente / asumido / a confirmar → a qué fuente o a quién ir)
  4. Nivel de madurez honesto (hipótesis de screening / parcialmente validado / listo para decisión)
  5. Qué falta para decidir
  6. Factores de ejecución: inversión, tiempo a mercado, capacidades, regulatorio
- **Principio de veracidad a NIVEL DATO (load-bearing):** cada dato se marca **establecido** (verificado,
  con fuente) o **a juicio** (no estimable de forma confiable → el sistema da insumos y anclas reales,
  NUNCA un número inventado). En particular: el modelo **sobreestima tiempos** (priors viejos; ej. estimó
  "varios meses", real ~2 semanas con revisiones) → nunca confiar en timelines generados; anclar en
  comparables o dejarlo al humano. Mismo trato para inversión, capacidades y regulatorio (este último =
  incógnita conocida por la burocracia).

## 4. Fix datos.gob.ar (`market_agent/tools/datosgobar.py`) — el histórico "nunca conecta"

- **Diagnóstico (verificado en vivo, NO era falta de conexión — la API anda):**
  1. El filtro `organization` usaba slugs **inexistentes** ("magyp"/"indec"/"senasa") → `fq` devolvía
     **0 en silencio** (falso vacío). Slugs reales: **`agroindustria`** (MAGyP + SENASA) y **`sspm`**
     (macro/INDEC).
  2. Solo usaba CKAN `package_search` (metadatos de datasets), ignoraba la **API de Series**
     (`apis.datos.gob.ar/series`) que da los NÚMEROS reales (faena, producción, precios).
- **Fix aplicado y verificado en vivo:** mapeo de slugs `_resolve_org` + red de seguridad (si el filtro
  da 0, reintenta sin filtro → mata el falso vacío) + funciones nuevas `search_series` +
  `get_series_values`. Verificado: `senasa` ahora trae datasets; series de faena devuelven valores 2025-26.
- Pendiente: wirear `search_series` como tool de los agentes (diferido al rework de agentes); tests formales.

## 5. Propuesta inicial de agentes (a ANALIZAR — no decidida)

Recorte por **competencia de fuente** + un Armador que impone honestidad + un Orquestador que maneja las
puertas de entrada. 4 agentes + orquestador + cañería:

- **Orquestador** (humano hoy) — recibe la puerta de entrada, formula tesis candidatas, decide qué
  investigar, ensambla. Llena el bloque 1.
- **Evidencia Científica** (amplía el científico) — factibilidad técnica, estado del arte, el dolor a
  nivel biológico; recencia obligatoria + prioridad local. Cruce 2 + parte del cruce 1.
- **Mercado y Datos Oficiales** (repotencia el de mercado, ya con la conexión arreglada + API de Series) —
  demanda/tamaño, precios, competencia registrada (SENASA), regulatorio, anclas de inversión/tiempo.
  Cruces 1/3/4 + insumos del bloque 6.
- **Investigación Amplia** (NUEVO — el que faltaba; lo del caso "olor") — mapea a lo ancho el espacio de
  soluciones / competencia / estado del arte. Cruce 3 + entradas tipo "sector"/"planta".
- **Armador del Expediente** (transforma el convergente: de decisor → armador) — ensambla los 4 cruces +
  factores de ejecución, etiqueta cada dato establecido/a-juicio, marca gaps con "a qué fuente ir", asigna
  madurez. **No inventa números, no elige finalista.** Bloques 3/4/5/6.
- **Cañería (no son agentes):** conectores de ingesta (CONICET OAI / SNRD / Series) — hoy no existen; +
  motor del KM (ya existe) como sustrato.

**¿Estos agentes u otros? Mezcla:** se conservan Científico (→Evidencia) y Mercado (repotenciado); se
transforma Convergente (→Armador, sin embudo N→1); se redefine/absorbe el Divergente (su generación se
reparte en Orquestador + Investigación Amplia → redundante como agente aparte); se suman Investigación
Amplia + los conectores. El eje deja de ser el embudo demand-first y pasa a ser **el expediente**.
