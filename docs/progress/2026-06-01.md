## Decisiones tomadas

| Decisión | Razón |
|---|---|
| Modelo por agente: Scout=Sonnet, Especialista=configurable | Economía de tokens — Opus solo donde justifica el costo |
| Scout desacoplado del ruteo | Los puntos de entrada varían (empresario vs. investigador); el ruteo es del Orquestador |
| `agent.py` → `specialist_proteins.py` | Naming consistente para arquitectura multi-especialista |
| GMO+peletizado como contexto, no criterio | No restringir candidatos que no usan esa vía |
| Subcontratación válida como ruta de producción | Si la oportunidad lo justifica, se puede tercerizar |
| Nutrición humana B2B incluida en el scope | Amplía el universo de candidatos sin cambiar el modelo de negocio |
