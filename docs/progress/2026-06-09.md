### 2. Conexión del MCP al agente divergente
`test_metodologia.py` ahora llama automáticamente al Knowledge Module al terminar cada corrida:
- Guarda la Corrida con metadatos (sector, modelo, tokens, costo estimado)
- Extrae oportunidades estructuradas del output usando Claude Haiku
- Guarda cada oportunidad con deduplicación semántica

El import del KM es tolerante a fallos (`try/except`): si el KM no está disponible (falta `.env`,
Neon caída, etc.), la corrida continúa y solo avisa. No bloquea el agente divergente.

**Archivo creado:** `knowledge_module/ingest_corrida.py`
- `km_ingest()` — función sincrónica, llama `asyncio.run()` internamente
- `extract_opportunities_from_output()` — pasada de extracción con Haiku, devuelve JSON estructurado
- CLI para ingestión standalone: `python ingest_corrida.py <output.md> "<sector>"`

Migración completa RunPod → Modal. Larga batalla de compatibilidad de dependencias resuelta:

- **Imagen base:** `nvcr.io/nvidia/pytorch:23.06-py3` para preservar apex/fused_layer_norm_cuda

**Endpoint:** `https://criza-dev--criza-esmfold-esmfold-server.modal.run`  
`.env` actualizado — `ESMFOLD_POD_URL` apunta a Modal.
