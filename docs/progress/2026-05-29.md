## Decisiones tomadas y por qué

| Decisión | Razón |
|---|---|
| OpenAlex como fuente primaria | Rate limiting de Semantic Scholar degradaba análisis silenciosamente |

| Telegram como primera interfaz | Más rápido que web app, mobile-first, ideal para aprobación de acciones |
| team readiness ahora | Más difícil agregar estructura de equipo retroactivamente |

## Problemas encontrados

- **Anthropic rate limit (30k tokens/min)**: el agente hacía 9 búsquedas con 15-20 resultados cada una → contexto demasiado grande. Fix: retry con backoff en `agent.py` + instrucción de max_results=8 en el query de scouting.
- **PowerShell escaping**: comandos con strings multilínea y caracteres especiales requieren escribir scripts a archivo en vez de usar `-c` inline.
- **RunPod H200 port 8000**: nuevo pod no tenía puerto 8000 expuesto por defecto — configurar en Edit Pod → HTTP ports.
