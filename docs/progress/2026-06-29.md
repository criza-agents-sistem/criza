## Lo que se hizo

### Fix: encoding bugs en `download_pdfs.py`

El run anterior (2026-06-27) procesó ~696 docs pero dejó ~15-20 con error:

- **Bug 1 — null bytes (`\x00`):** pypdf extrae strings con bytes nulos de algunos PDFs. PostgreSQL UTF-8 los rechaza con `CharacterNotInRepertoireError`.
- **Bug 2 — surrogates (`\udf38`):** PDFs con encoding roto generan strings Python con lone surrogates, que asyncpg no puede serializar a UTF-8.

**Fix:** se agregó `_sanitize()` en `criza/ingest/download_pdfs.py`:
```python
def _sanitize(text: str) -> str:
    text = text.replace('\x00', '')
    text = text.encode('utf-8', errors='surrogatepass').decode('utf-8', errors='ignore')
    return text
```
Aplicado en `_update_texto()` antes del INSERT.
